# MapReduce Datasets

Sample datasets for practicing MapReduce operations.

## Files

### Text Processing
- **`sample_text.txt`** - Text about MapReduce concepts and architecture
- **`sample_bigdata.txt`** - Text about Big Data technologies and tools

## Usage

These datasets are used in the MapReduce examples:

```bash
# From 02-file-processing directory
python wordcount_file.py ../../../../datasets/mapreduce/sample_text.txt
python wordcount_multifile.py ../../../../datasets/mapreduce/
```

## Adding Your Own Data

Feel free to add your own `.txt` files here for practice. The MapReduce examples can process any text file.
