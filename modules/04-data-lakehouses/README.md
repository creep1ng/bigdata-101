## Prerequisites

- Databricks Runtime 13.x+ (includes Delta Lake)
- Azure Data Lake Storage Gen2 (Storage Account with hierarchical namespace)

## Setup — Azure Data Lake Storage Gen2

### 1. Create the Storage Account
- In Azure Portal → Create Storage Account
- Enable **"Hierarchical namespace"** (this turns it into ADLS Gen2)
- Note down the storage account name

### 2. Create the container
- Inside the Storage Account → Containers → `+ Container`
- Name: `bigdata`

### 3. Upload the datasets
Upload the 7 Uber Travel Times CSVs to this path inside the container:

```
bigdata/
└── landing/
    └── uber/
        ├── Travel_Times - Bogota.csv
        ├── Travel_Times - Boston.csv
        ├── Travel_Times - Johannesburg and Pretoria.csv
        ├── Travel_Times - Manila.csv
        ├── Travel_Times - Paris.csv
        ├── Travel_Times - Sydney.csv
        └── Travel_Times - Washington DC.csv
```

You can upload the files from:
- Azure Portal → Storage Account → Containers → bigdata → Upload
- Azure Storage Explorer (desktop app)

### 4. Get the Access Key
- Azure Portal → Storage Account → Security + networking → Access keys
- Copy **key1**

### 5. Configure in the notebooks
In each notebook, replace these variables:
```python
STORAGE_ACCOUNT = "<your_storage_account>"   # e.g.: "introbigdataupb"
CONTAINER       = "bigdata"
ACCESS_KEY      = "<your_access_key>"        # key1 from the previous step
```
